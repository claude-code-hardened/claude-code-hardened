# i18n 迁移规范

本文档说明如何把新的用户可见 UI 字符串接入 i18n 系统，以及贡献新翻译的规范。

## 架构

- **方案**: i18next，自然键（natural-key）模式——英文原文即 key。
- **核心模块**: `src/i18n/index.ts`（`t()`、`currentLocale()`、`resolveLocale()`），纯逻辑在 `src/i18n/normalize.ts`。
- **语言包**: `src/i18n/locales/<tag>.json`——扁平 string→string 映射，已有 `zh-CN`、`zh-TW`、`ja`、`ko` 四个包（`en` 即源码原文，无需语言包条目）。
- **语言解析顺序**: `settings.json` 的 `uiLocale` > `CLAUDE_LANGUAGE` 环境变量 > `LANG` > 英文。
- **回退**: 未翻译的 key 原样返回英文，永不抛错；locale 包缺失时整个系统静默降级。

## 什么该翻译，什么不该

| 类别 | 处理 | 例子 |
|------|------|------|
| 用户可见 UI 文本 | ✅ 用 `t()` 包裹 | 权限对话框选项、加载提示、esc 快捷键提示 |
| 命令帮助 / 错误信息 | ✅ 用 `t()` 包裹（逐步迁移） | `/resume` 列表加载、API 错误摘要 |
| **给模型看的文本** | ❌ 保持英文 | 工具 prompt、系统提示词、tool_result 内容（如 query.ts 的 `'Interrupted by user'`——它同时是回传给模型的 tool_result） |
| 日志 / 调试输出 | ❌ 保持英文 | `logForDebugging`、analytics |
| Spinner 动词 | 特殊通道 | `src/i18n/spinnerVerbs.ts` 的 `LOCALE_SPINNER_VERBS`（数组不走 t()） |

判断标准：**这段字符串会被送进 API 请求体吗？** 会 → 不翻译。

## 接入新字符串

```tsx
// 1. import（路径按文件层级调整）
import { t } from '../../i18n/index.js';

// 2. 包裹字符串字面量——key 就是英文原文
<Text>{t('Do you want to proceed?')}</Text>

// 3. 在 locale 包中添加同 key 翻译
//    src/i18n/locales/zh-CN.json 等（zh-CN 与 zh-TW 必须同步；
//    ja/ko 为部分包，可后续补充，缺失 key 自动回退英文）
"Do you want to proceed?": "要继续吗？",
```

规则：

1. **key 必须与英文原文逐字节一致**（含空格、省略号 `…`、标点）。前导/尾随空格保留在 key 中（如 `'(esc to interrupt '`）。
2. **zh-CN 与 zh-TW 语言包必须同步更新**——`src/i18n/index.test.ts` 有 key 集合一致性测试，缺失会挂 CI。ja/ko 为部分包（best-effort），只需是 zh-CN key 集的子集，缺失 key 回退英文。
3. **禁止翻译值为 key 原文**（stub 检查测试会失败）。
4. **插值已支持**：i18next 风格 `{{name}}` 占位符——`t('Loaded {{n}} messages', { n: 5 })`。语言包中的 key 与 value 均保留占位符原文；英文路径在 `t()` 内本地替换（`src/i18n/index.ts:80-88`），缺失的变量名原样保留。

## 基准迁移状态

I2/I3 批量迁移素材在 `docs/i18n-pending/`（8 个 batch）——**8/8 批已定案**（batch-3 经清洗定案：325 条中 301 条为测试填充垃圾，有效新增 0，语言包本已完备）。2026-09-13 完成三批调用点接线：组件 Top10 218 处、命令层 170 处（模型侧消费被 `source!=='builtin'` 过滤排除，已核实）、次级组件 62 处——语言包现为 **2592 keys**（zh-CN = zh-TW）。已接入 `t()` 的 UI 面：

- 权限对话框：`PermissionPrompt.tsx`（question）、`FilePermissionDialog/permissionOptions.tsx`（Yes/No/session 选项 + placeholder）、`PermissionExplanation.tsx`
- 会话恢复：`resume.tsx`、`ResumeConversation.tsx`（Loading 提示）
- Spinner：`SpinnerAnimationRow.tsx`（esc 提示）、`constants/spinnerVerbs.ts`（动词列表）
